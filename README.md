## 🚀 Yerel Çalıştırma

```bash
# 1) Repoyu kopyala
git clone https://github.com/TARIKELER-TARNAK/TARIKELER-TARNAK.github.io.git
cd tarikeler.github.io

# 2) Herhangi bir statik sunucu ile aç
python -m http.server 8000
# tarayıcıda: http://localhost:8000
```
