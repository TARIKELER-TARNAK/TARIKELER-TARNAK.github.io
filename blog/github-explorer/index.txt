13:T4af,<h1>GitHub Explorer</h1>
<p>Bu sitedeki <strong>GitHub</strong> sayfası, GitHub API&#39;sini kullanarak istediğin kullanıcının repolarını listeler. Bir repoya tıkladığında ise <strong>README</strong> ve <strong>dosya ağacı</strong> görüntülenir.</p>
<h2>Kullanılan API&#39;ler</h2>
<ul>
<li><code>GET /users/{username}/repos</code> → Repo listesi</li>
<li><code>GET /repos/{owner}/{repo}</code> → Repo detayı (varsayılan branch)</li>
<li><code>GET /repos/{owner}/{repo}/readme</code> → README içeriği (Base64)</li>
<li><code>GET /repos/{owner}/{repo}/git/trees/{branch}?recursive=1</code> → Dosya ağacı</li>
</ul>
<h2>README&#39;deki Görseller</h2>
<p>Markdown içindeki göreli görsel yolları şöyle çözülüyor:</p>
<pre><code class="language-ts">// ./docs/resim.png →
https://raw.githubusercontent.com/{owner}/{repo}/{branch}/docs/resim.png
</code></pre>
<h2>Neden Yararlı?</h2>
<ul>
<li>Açık kaynak projeleri anında incele</li>
<li>Repoları tek sayfada karşılaştır</li>
<li>İlham alacak yeni projeler keşfet</li>
</ul>
<blockquote>
<p>İpucu: GitHub bölümüne örneğin kendi kullanıcı adını yaz ve repolarını keşfet!</p>
</blockquote>
