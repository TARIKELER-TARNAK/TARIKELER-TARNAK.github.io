🎮 TarnakLua-Roblox

Roblox için Lua tabanlı araç ve script projesi.

Rayfield UI kütüphanesiyle modern bir arayüze sahip Roblox Lua scripti.

⚠️ Sorumluluk reddi: Oyun içi araçlar (exploit) Roblox kullanım koşullarını ihlal edebilir ve hesap yasağına yol açabilir. Kullanım tamamen kullanıcının kendi sorumluluğundadır.

✨ Özellikler

Özellik Açıklama
🎛️ Rayfield UI Modern, kullanıcı dostu grafik arayüz
⌨️ Kısayol Açma/Kapama: PageDown veya Break tuşu
🏃 Hareket Yürüme hızı, zıplama gücü ve yerçekimi ayarları
💡 Ortam Işıklandırma, saat, sis ve ortam renk ayarları
🔄 Sıfırlama Tüm ayarları orijinal değerlere döndürme

🚀 Kullanım

  1. Roblox'ta bir exploit yürütücüsü (executor) açın
  2. TarnakHack.lua dosyasının içeriğini kopyalayın
  3. Executor'a yapıştırıp çalıştırın
  4. Arayüzü açmak için PageDown veya Break tuşuna basın
