🤴🏽 Hard-fork of Franz, adding awesome features and removing unwanted ones.

Accentra is a desktop app that helps you organize how you use your favourite apps by combining them into one application. It is based on Franz - a software already used by thousands of people - with the difference that Accentra gives you many additional features and doesn't restrict its usage! Furthermore, Accentra is compatible with your existing Franz account, so you can continue right where you left off. Please find out more about Accentra and its features on accentra.org.

Styling

You can style Accentra's UI with the USER_DATA/Accentra/config/custom.css file.

Note

USER_DATA's location depends on your platform:

  • Windows: %APPDATA%
  • Linux: $XDG_CONFIG_HOME or ~/.config/
  • MacOS: ~/Library/Application Support
